# Repository Analysis Plan: BladderDIVE

## Overview
BladderDIVE is a comprehensive Snakemake-based bioinformatics pipeline for analyzing 23-channel CellDIVE multiplexed immunofluorescence data from bladder tissue samples.

## Pipeline Stages (Snakefile)

1. **segmentation** - Cell segmentation using StarDist + membrane refinement
2. **analysis** - Single-cell analysis (log/z-norm, UMAP, Leiden, K-means)
3. **cell_typing** - Assign cell types based on marker expression
4. **visualizations** - UMAP plots, heatmaps, spatial maps
5. **qupath_export** - Export to QuPath format (GeoJSON)
6. **spatial_analysis** - Neighborhood analysis, cell interactions
7. **quality_control** - QC reports and validation
8. **generate_report** - HTML report generation

## Key Features

- **23-channel marker panel**: CD45, CD3E, CD8a, CD20, CD68, PANCK, EPCAM, VIM, Ki67, etc.
- **Deep learning segmentation**: StarDist for nuclei detection
- **Cell typing**: 20 predefined cell types (T cells, B cells, macrophages, fibroblasts, etc.)
- **QuPath integration**: Pathologist annotations support
- **Napari visualization**: Interactive multi-channel viewing
